# AGENTS.md

## Scope

This repository is gq-theme, the placeholder WordPress theme every GETQUICK site
installs; a site's pages render in its Frontend, never here. Which repository
owns what:
[gq-platform ADR 0001](https://github.com/Quick-Release/gq-platform/blob/main/docs/adr/0001-ownership-of-work-across-getquick-repositories.md).

Read any repository for evidence. Write code, proofs, research and issues only
in the repository that owns them. File the rest in the owning repository, or
in Quick-Release/gq-platform when the owner is unclear, and stop.
